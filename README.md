# タマのけいさんドロップス（タマドロ）

小学校低学年向けの計算練習 WEB アプリです。たしざん・ひきざん・かけざん・百マスたしざんを解いて、ドロップを集めます。

## ローカルで動かす

画像などを `/img/...` のように「サイトのいちばん上から」の場所で読み込んでいるので、ファイルを直接開くのではなく、かんたんなサーバーで開きます。

```sh
python3 -m http.server 8765
# ブラウザで http://localhost:8765/ を開く
```

## 画面のしくみ

`index.html` 1枚のアプリです。URL の `#` のうしろで画面が切り替わります（`js/app.js`）。

| URL | 画面 |
|---|---|
| `#/` | さいしょの画面 |
| `#/add` `#/sub` `#/multi` `#/hundredgrid` | そのモードのレベル選択 → 問題 |
| `#/records` `#/records/add` など | タマのきろく（ドロップびん・カレンダー・タイムのうつりかわり・にがてマップ） |

以前の URL（`tamaadddrops.html` など）のページはなくなりました（開くと 404 になります）。

## にがてちょうせん（たしざん・ひきざん・かけざん）

1問ごとに「苦手HP」（0〜30）を記録しています（`js/history.js`）。

| できごと | 苦手HP |
|---|---|
| まちがえた | +10 |
| 正解したけれど 4.5秒以上かかった（かくれにがて） | +3 |
| 3.5秒以内に正解した | −2 |

- レベル選択画面の「🔥 にがてちょうせん！」で切り替えます。レベルごとのボタンに、にがてな問題の数（`🔥3`、なければ `✨`）が出ます。にがてな問題がないレベル（まだ一度もあそんでいないレベルもふくむ）は、にがてちょうせん中は押せません。
- レベルを選ぶと、そのレベルの苦手HPが高い3問を、4周（計12問）出します。にがてが3問に足りないときは、ふつうの問題でうめます。
- 「👑 特訓コース」は、解放されたすべてのレベル（「5は2と」のような分けるレベルはのぞく）からにがてを集めます。ごほうびのドロップは、いちばんにがてな問題のあるレベルのドロップです。にがてな問題が1つもない（まだ あそんでいない など）ときは、押せません。
- 4回ともまちがえずに、平均3.5秒以内で答えられた問題は「✨卒業（HP 0）」になります。とてもにがてだった問題は「🔥パワーダウン（HP 8・あと1かい）」になります。
- にがてちょうせんの回は、ベストタイムやタイムのうつりかわりには入れません（記録には `weakChallenge: true` がつきます）。
- 出しかたは `js/engines/drill.js` の `WEAK_DECK_STYLE` で変えられます（`'intensive'`：いまの12問 ／ `'blend'`：苦手3問×3回＋まぜる問題6問の15問）。

## かけざんのレベル

1つの段に3つずつ（「n のだん」「n:さかさ」「n:バラバラ」）で Lv1〜27。そのあとに、Lv28 子オニ（青）（1〜5の段のバラバラ）、Lv29 子オニ（赤）（6〜9の段のバラバラ）、Lv30 オニ（黒）（すべての段）があります。オニの3つは、すべての段の「バラバラ」でドロップを1こ以上とると出てきます。ノーミスクリアで金のドロップ20こがもらえるのは Lv30 だけです。

## タマのきろく：ドロップびん

- びんは、コルクのふたの ガラスびん（太い胴・短く丸い肩・胴の73%の口）の形です。形は `js/records.js` の `buildJarShape` で決めていて、当たり判定（`collideWithJar`）と描画（`jarPath`）の両方がこれを使います。
- びんを開くと、ドロップがみんな同じ大きさでつまった状態からはじまり、新しいドロップ（さいごの8こまで）が上から落ちてきます。
- びんをタップするたびに、100こが1つの「100玉」に合体します。100玉が5こたまると、つぎのタップで「500玉」になり、500玉が2こたまると、つぎのタップで「1000玉」になります。
  合体するときは、粒がうずを巻いてグワッと吸いこまれ（光の輪・集中線・びんのふるえ）、ほんの一瞬 止まってから、パキーンとはじけます（びん全体の光・衝撃波・ガラスのかけら・まわりの玉を押しのける・「100!」「500!」「1000!」の文字）。
  演出は 100玉（白と水色）→ 500玉（ピンク・衝撃波2重）→ 1000玉（金色・衝撃波3重）と、大きな玉ほど派手で大きくなります。強さや色は `js/records.js` の `DropJar.FX`（100玉・500玉・1000玉それぞれ）で変えられます。
- ドロップが350こより多いときは、重くならないように 粒を間引いて描きます（`MAX_VISUAL_BALLS`。たとえば3589こなら、1つぶが約10こ分）。
  100玉・500玉・1000玉は合体すると正確な数になります。100こに満たない のこりの粒は、合体のたびに少しずつ（のこりの数 ÷ のこりの合体の回数）さりげなく「ほどけ」、さいごの合体で ちょうど ほんとうの数（3589こなら89こ）になります（`unpackSome`）。
- ぜんぶ合体したあとにタップすると、コルクのふたがポンと開いて、ドロップが飛び出します。
  コルクは、口に差しこむ部分が抜けるまでは まっすぐ上に抜け、抜けたら回りながら飛びます。落ちてきて傾いていると、角が口のふちに当たって跳ねかえり（3回まで）、まっすぐになると口にすべりこんで、コトンと小さく跳ねて おさまります（`stepLid`、`LID_...`）。
- ふた（口のふちより上）をタップすると、いつでも びんがコテンとたおれて、ドロップが画面いっぱいのテーブルにコロコロちらばります（`js/drop-table.js` の `DropTable`）。
  - テーブルは上から見たところ（重力なし）で、摩擦で止まります。色は びんのカードと同じ水色で、うしろの きろくの画面が 少しぼやけて すけて見えます（`css/records.css` の `.drop-table-bg`）。
  - びんは 左上のすみに たおれて、口が 右下のすみを むきます。うしろには 粒が1つぶ通れる すきま（`GAP`）を あけます。
  - びんの中に見えていた粒が、びんと いっしょに たおれて、口のほうへ ころがって 出てきます（`POUR_PULL`）。口から出た粒は テーブルの大きさに ふくらみ、おうぎ形に とびだします。遠くまで とぶ粒から先に出して、しばらくは ほかの粒の上を はねて こえる（`HOP_FRAMES`）ので、まんなかに かたまりません。
  - 出てくるのは、たおした ときの中身です。合体した玉（100玉・500玉・1000玉）はそのまま、のこりの粒は ほんとうの数で出ます。ただし テーブルの3わり（`AREA`）を おおう数まで（多いときは へらして出す）。見えていた粒より多いときは、のこりを 口から つづけて出します。粒は びんの中より少し大きく（`SIZE_UP`）します。
  - 止まったら 指でつまんで動かせて、はじくと すべります。何本の指でも動かせます。
  - びんの ガラスのかべ・口のふちには 当たり判定があります。口は あいていて、指で入れたり、はじいて ころがしこんだり できます（中では びんの粒の大きさに ちぢむ）。まわりの粒に そっと おされただけでは 入りません。かべを すりぬけて 出入りすることは ありません（`hitWall`）。
  - 「おかたづけ」を おすと、まず びんが おきあがって きろくの定位置に もどります（中に入れておいた粒も いっしょに）。
    つぎに、口に近い粒から じゅんばんに（びんの うしろを通って）山なりに とんできて、口の上の 真上から まんなかあたりへ とびこみ、そのままの いきおいで 落ちていきます（口の上で 止まらない。`flyAt`）。底では まんなかに 山ができ、粒は 山の てっぺんに 落ちてから 斜面を ころがって 止まります。山は すそが うまって だんだん なだらかに なり、さいごは なだらかな山のまま です。さいごに コルクが とんできて ふたをします。
    びんは、たおす前の中身に もどります（`saveJar`・`restoreJar`）。合体した玉（100玉・500玉・1000玉）は ほどけず、玉のまま もどり、合体の つづき（のこりの合体）も そのままです。合体の とちゅうで たおしたときは、その合体は とりけして、つぎに タップしたときに やりなおします。
    テーブルの粒は、もとになった びんの粒の場所へ もどります。びんの おくに あった分（見えていなかった粒）は、テーブルに 出なかった びんの粒の かわりになり、あまったら 口で すいこまれて 見えなくなります。たりない分は 口の上から 入ってきます（テーブルに出る数が びんに見えている数より 少ない、小さい画面の ときだけ）。
    つもる場所は、その粒を なだらかな山の形に ならべなおして 先に 決めておきます（`moundLayout`。大きい玉も いっしょに。つもる とちゅうの けわしさ `HEAP_SLOPE`・さいごの なだらかさ `MOUND_SLOPE`・あつまってくる時間 `FILL_FRAMES`）。粒どうしで おしあう計算は しないので、つもった粒は ぴたっと 止まり、ふたが しまったあとの びんは、つもった 山の ならびと まったく同じです。
    ほかの画面へ行ったり 読みこみなおしたりすると、いつもどおり びんは つくりなおされます（合体は ほどける）。
  - ちらばった場所は保存しないので、ほかの画面へ行ったり 読みこみなおしたりしても、びんに もどっています。
- 落ちてきたドロップ（びんを開いたとき・ふたが開いて飛び出したとき）は、底や積もったドロップに強くぶつかると、玉1つぶんくらいまで跳ねます。
  跳ねるのは1つの玉につき2回まで。跳ねるたびに弱くなり、そのあとは今までどおりピタッと止まります。
  - 調整する数字は `js/records.js` の `DropJar` の上のほう（`BOUNCE_...`）にまとめてあります。
  - `BOUNCE_ENABLED: false` にすると、跳ね返りがなくなります（びんの形は いまのまま）。
  - 跳ね返りとびんの形を変える前の版（長方形のびん）は、ブランチ `anchor/dropjar-stable-6.3.6` に残してあります。`git checkout anchor/dropjar-stable-6.3.6 -- js/records.js index.html css/records.css` で、びんを元に戻せます。
  - `tests/dropjar.test.js` で、跳ねること・ずっと動きつづけないこと・びんの外や宙に浮いたまま止まらないこと を確かめています。

## よくある変更

- **レベルを追加・変更する**：`js/modes/addition.js` などの `levels` に1行足します。ボタンは自動でできます。
  ```js
  { label: 'Lv12もんだい', comment: 'こたえが20まで', drop: 'L',
    patterns: () => P.pairs(1, 9, 1, 9, (a, b) => a + b <= 20) },
  ```
- **ドロップの色を変える**：`img/drops/*.svg` の色（グラデーションの `stop-color` など）を直接書きかえます。
  （`tools/make_drops.py` は前のかんたんな球をつくるスクリプトなので、実行するといまのドロップが上書きされます）
  書きかえたら `node tools/make_drop_pngs.js` で、小さいドロップの PNG（`img/drops/small/`）もつくりなおします。
- **数字・記号・ひらがなの形を直す**：`tools/make_glyphs.py` の `BASE`（線の通り道）を変えて `python3 tools/make_glyphs.py`。
  字形は、教科書体の書き方のきまりに合わせて、タマドロのために一から描いたものです（フォントをなぞったものではありません）。
  あとで最終調整する点は、スクリプトの先頭に覚え書きがあります。
- **タマのセリフを変える**：`tashizan_message.json`。

## 保存データ（localStorage）

| キー | 中身 |
|---|---|
| `add_coins_3` など | レベルごとのドロップ（最新10こ）。画像名は以前のまま `/img/Lmaru.png` で記録し、表示のときに `img/drops/L.svg` にする |
| `addition_level_3_best_time` など | ベストタイム（百マスは秒、ほかはミリ秒） |
| `hundredgrid_level_3_records` など | 百マスのタイム（上位5件）・累積正答数 |
| `tamadoro.log.v1` | 1回あそぶごとの記録（いつ・レベル・時間・まちがい・ドロップ） |
| `tamadoro.stats.v1` | 1問ごとのできぐあい（回数・まちがい・時間・苦手HP `hp`。にがてマップ・にがてちょうせん用） |
| `tamadoro.schema` | 以前のドロップを記録に取りこんだしるし |

「データをセーブ」は localStorage をまるごと `tamadoro_月日時分.txt` に書き出します。

「データをロード」は、読みこみかたを2つから選べます。

- **いまのデータに たして よみこむ**：ファイルにあるデータだけ入れかえます。ファイルにないデータ（ほかのモードのドロップ・記録・設定）は、そのままのこります。
- **ぜんぶ うわがきして よみこむ**：いまの localStorage をぜんぶ消してから、ファイルのデータを入れます。ファイルがこわれているときは、何も消しません。

どちらも、読みこんだあとに `tamadoro.schema` がなければ（むかしのアプリのセーブファイルなど）、ドロップを記録に取りこみます。

## テスト

`tests/` に、ブラウザを自動で動かして確かめるテストがあります（Node.js と Playwright が必要）。

```sh
cd tests
npm install
npx playwright install chromium
npm test
```
