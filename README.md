# タマのけいさんドロップス（タマドロ）

小学校低学年向けの計算練習 WEB アプリです。たしざん・ひきざん・かけざん・百マスたしざんを解いて、ドロップを集めます。

## ローカルで動かす

画像などを `/img/...` のように「サイトのいちばん上から」の場所で読み込んでいるので、ファイルを直接開くのではなく、かんたんなサーバーで開きます。

```sh
python3 -m http.server 8765
# ブラウザで http://localhost:8765/ を開く
```

## 画面のしくみ

`index.html` 1枚のアプリです。URL の `#` のうしろで画面が切り替わります（`js/app.js`）。

| URL | 画面 |
|---|---|
| `#/` | さいしょの画面 |
| `#/add` `#/sub` `#/multi` `#/hundredgrid` | そのモードのレベル選択 → 問題 |
| `#/records` `#/records/add` など | タマのきろく（ドロップびん・カレンダー・タイムのうつりかわり・にがてマップ） |
| `#/music` | おんがくのへや（ためしているあいだは `/music on` のときだけ。下の「おんがくのへや」） |
| `#/keys` | けんばんの レベル選択 → レッスン（`/music on` のときだけ） |
| `#/black` | くろいけんばんの レベル選択 → レッスン（`/music on` で、けんばんの Lv6 を クリアしたあと） |
| `#/notes` | おんぷよみの レベル選択 → レッスン（`/music on` のときだけ） |
| `#/rhythm` | リズムの レベル選択 → レッスン（`/music on` のときだけ） |
| `#/piano` | じゆうにひこう（`/music on` のときだけ） |

以前の URL（`tamaadddrops.html` など）のページはなくなりました（開くと 404 になります）。

## おんがくのへや（ためしているところ）

- 設定（歯車）の入力欄に `/music on` と入れると、さいしょの画面に「おんがくのへや」のボタンが出ます（`/music off` で かくれます）。入力欄は、さいしょの画面にも 計算の画面にもあります。`/rescue` `/delete` `/master on` は、計算・けんばんの画面でだけ使えます。
- へやの中は「けんばん」「くろいけんばん」「じゆうにひこう」「おんぷよみ」「リズム」。右上の「おと あり／なし」は、テンキーの音などもふくめて ぜんぶの音に効きます。
- 音は `js/sound.js` でつくります（ピアノふうの音を その場でつくるので、音のファイルは いりません）。けんばんは さわった しゅんかん（`pointerdown`）に鳴り、何本の指でも おせます。おんがくの画面に いるあいだは、iPhone のマナーモードでも 音が出るようにしています（`navigator.audioSession`。使えないブラウザでは いままでどおり）。
- 音のデータ（`js/notes.js`）は、「どの けんばんか（MIDI の番号。60 が まんなかのド）」と「どんな名前か（ド〜シ と ♯♭）」を べつに持ちます。黒いけんばんには 名前が2つ（ド♯／レ♭）あります。

| Lv1 ドレミ | ド・レ・ミ を 4かいずつ（12もん） | あり |

| Lv5 ファ〜ド | ファ〜たかいド | あり |
| Lv6 ド〜ド | ド〜たかいド を 2かいずつ（16もん） | なし |
| Lv7 メロディ | 3〜4おんの メロディを 左から じゅんばんに（8もん）。和音の じゅんばん C → F → G（G7）→ C で出し、C にもどるときは ドで おわる | なし |
| Lvオニ | Lv1〜7 を ぜんぶ まぜる（1おん12もん＋メロディ4もん）。見せる けんばんの はしが 毎回かわる（ファ〜ミ・ミ〜ミ・ファ〜ファ・シ〜シ。どれも 黒いけんばん 10こ） | なし |

- けんばんは、左はしが ドに ならないように、すこし よぶんに見せます（黒いけんばんを 目じるしに ドを さがす力を つけるため）。
  はしでは、黒いけんばんの かたまり（3こ・2こ）を かけさせません（3・2・3・2 と くりかえして見える）。かけると、3この かたまりが 2こに見えて、そこも ドに見えてしまうからです。Lv1〜4 は ファ〜シ、そのほかは ファ〜ミ です。そのレベルで使う けんばんは あかるく、そのほかは うすく見せます。うすい けんばんも 押せば鳴りますが、まちがいには なりません。
- まちがえた けんばんも 鳴って、「ミだよ」のように 何を おしたかを ふきだしで見せます。正解すると、その音を ふくむ和音が 小さく ポロロンと鳴ります（ド・ミ・ソ → C、ファ・ラ → F、レ・シ → G）。
- 解放は、おとあそびの ドロップ1こで Lv1、オニは Lv7 の ドロップ5こ、ほかは 3こ。まちがいの上限（5かい）・5もんごとの金のドロップ・ノーミスで金のごほうび・まちがえた問題を さいごにもういちど は、計算と同じです。
- 1もんごとの きろく（`tamadoro.stats.v1` の `keys`。キーは「ド」「たかいド」「ドレミ」など）と、1回ごとの きろく（`tamadoro.log.v1`）を のこします。ドロップは びん・カレンダーに入りますが、「タマのきろく」の けんばんの タブ・「にがてちょうせん」は まだありません。
- 正解ごとの ドロップは、上の ばらばらな場所から おちてきて、けんばんの上に 左から ならびます（大きさは 32px。計算の 50px より 小さく、めだちすぎないように。`KEYS_PILE_SIZE`）。画面の はしまで ならんだら、2だんめは 1だんめの ドロップと ドロップの あいだに はまって つもります（`keysPileSlot`）。つもりつづけると 問題も 見えなくなりますが、それで かまいません。つもった ドロップは 指で うごかせます。レベル選択へ もどると とびちります。
- クリア・ざんねんの カードは、画面の 上のほうに 出します（けんばんの上に つもった ドロップと かさならないように。カードは ドロップより手前）。

### くろいけんばん（`js/modes/black.js`。問題の進め方は けんばんと同じ `js/engines/keys.js`）

- 「♯（シャープ）は すぐ みぎどなり、♭（フラット）は すぐ ひだりどなり」の きまり 1つで さがします（「♯は 黒いけんばん」とは 教えない）。
- 黒いけんばんで 正解すると、聞かれたのが どちらの名前でも、その けんばんの上に 2つの名前（「ド♯／レ♭」）を出します。くりかえすうちに 2つの名前が むすびつきます。
- けんばんの Lv6（ド〜ド・もじなし）で ドロップを 1こでも もらうと ひらきます（`keys_coins_7`）。それまでは、おんがくのへやの ボタンに カギがかかり、「しろい けんばんの Lv6 を クリアすると ひらくよ」と出ます。ためすときは、けんばんの画面で `/rescue` → Lv7 まで ひらくと、ここも ひらきます。

|---|---|---|
| Lv1 ♯ | ド♯・レ♯・ファ♯・ソ♯・ラ♯ を 3かいずつ（15もん） | もとの音を 光らせて「→」・白いけんばんの名前 |
| Lv2 ♭ | レ♭・ミ♭・ソ♭・ラ♭・シ♭ を 3かいずつ（15もん） | もとの音を 光らせて「←」・白いけんばんの名前 |

### おんぷよみ（`js/modes/notes.js`。五線の絵は `js/staff.js`、問題の進め方は けんばんと同じ `js/engines/keys.js`）

- ト音記号の 五線に 出た 音符を 読んで、その けんばんを おします（`display: 'staff'` で、名前の カードの かわりに 五線）。
- 五線・ト音記号・音符は SVG で 描いています（`TamaStaff`。音符は ぜんぶ 4ぶおんぷ。シより上は ぼうが 下むき。ド・上のラ には みじかい せん＝加線）。
- はじめは けんばんに 名前を書いておき（読むことに 集中）、Lv5 からは 名前なしで「五線の場所 → けんばん」に します。
- メロディは 1つの 五線に ならび、いま 読む 音符が ピンク、読みおわった 音符が みどりに なります。正しく 読んだ 音符は キラリンと 光ります。
- さいしょの「しくみ」は、せつめいしながら すすみます（8もん。まちがえても しっぱいに ならず、どこを 見るかを おしえます。ドロップは いつも その レベルの 色）。けんばんを おすと、その音の 名前を その高さで うたいます（`js/sing.js` の「どー・れー・みー」）。
  1. **せんは 5ほん**：五線の せんを、いちばん下から じゅんばんに タッチして「1ぽんめ・2ほんめ・3ぼんめ・4ほんめ・5ほんめ」と かぞえます（はじめは 1ぽんめが やさしく 点滅して「おしてね」。かぞえた せんは 青く 光って よこに「1ぽんめ」など。とばすと「1ぽんめは いちばん下の せんだよ」）。
  2. **ドの ばしょ**：ドは、五線の 下に みじかい せん（加線）を 1本 たした ところ（みじかい せんが 光り、ドの けんばんに ポワンポワン 光る わっか）。
  3. **のぼる**：ド→たかいド。音符が 1つずつ あらわれ、下に「せん」「あいだ」の ふだが 出ます（ド・ミ・ソ・シ は せん、レ・ファ・ラ・たかいド は あいだ。レは ドの みじかい せんと 1ばん下の せんの あいだ）。正しい けんばんを おすと、その 音符が キラリンと 光り（★）、すこし あとに つぎの 音符が あらわれます（おした音が つぎの 音符だと まちがえないように。キラリンの あいだに おした けんばんは 鳴るだけ）。
  4. **くだる**：たかいド→ド。
  5. **れんしゅう**：ドレミファソラシド・ドシラソファミレド と、とちゅうからの のぼり・くだり（4〜5おん）を つづけて 読みます。
- しくみで ドロップを 1こ もらうと Lv1 が ひらきます（オニは 5こ、ほかは 3こ）。
- **おだんご**（Lv1〜Lv4・Lv6）：和音の 3つの 音を、1本の くしに さした おだんごで 見せます。おだんごの 色は 音の 色（けんばんの 名前の 色を あわくした もの。ド 赤・レ オレンジ・ミ 黄・ファ 緑・ソ 青・ラ 藍・シ 紫）なので、ドミソ と レファラ は ちがう 色、シは 紫、たかいドは ドと 同じ 色です。Lv1 は せんに ささった おだんご（ド・ミ・ソ）、Lv2 は せんの あいだの おだんご（レ・ファ・ラ）。
  - あたらしい おだんごが 出る レベルは、さいしょに お手本：おだんごの よこに 名前が 出て、おす けんばんに ポワンポワン 光る わっか（おすと つぎの けんばんへ）。
  - あとは「1おん」と「おだんご」を まぜて 出します（Lv1・Lv2 は 3つの 音を 3かいずつ ＋ おだんご 3かい）。おだんごは 下から じゅんばんに おし（いま おす おだんごに ピンクの わっか）、そろうと その 和音（C・Dm）が 鳴ります。1おんの 問題で 正解したときの 和音も、その音の おだんごの 和音です（Lv1 は C、Lv2 は Dm だけ）。Lv4 の 1おんは、これまでと 同じ ひびき（ド・ミ・ソ と たかいド は C、レ・ファ・ラ は Dm、シは ミ・ソ・シ＝Em）で、4つだまの 和音（Cmaj7・Dm7）は おだんごが そろった ときだけ 鳴ります。
  - けんばんを おすと 名前を うたいます（しくみと 同じ）。
- レベルの ならびを かえたので、まえの おんぷよみの ドロップ・ベストタイム・きろくは、はじめて 開いたときに 1回だけ 消します（`dataVersion`。`tamadoro.notes.dataVersion` に 版を おぼえる）。

### リズム（`js/modes/rhythm.js`・`js/engines/rhythm.js`）

- 右から 流れてくる がくふが、ピンクの せんに 来たときに たたきます。画面の どこを たたいても よく（ボタンの上は のぞく）、パソコンでは スペースキーなどでも たたけます。たたくと すぐ ポンと鳴ります。下の たいこは めじるしです。
- ことばは 学校と同じ「タン（4ぶおんぷ）・タタ（8ぶおんぷ 2こ）・ウン（4ぶきゅうふ）・ターアー（2ぶおんぷ）」。音符の下に 書いてあります。がくふは 1本線に 音符・やすみを SVG で 描いています。
- はじめに「1・2・3・4」（1しょうせつ）の カウントがあり、メトロノームが ずっと鳴ります（1はくめは 高い音）。「▶ おてほん」で たいこの おてほんを 聞いてから「🥁 スタート」。
- 拍は 音の時計（AudioContext）で きめます。メトロノームと おてほんの たいこは、はじめに まとめて 予約して 鳴らします（`setTimeout` では ずれるので）。たたいた 時刻は「そのとき スピーカーから 出ていた 音」の 時刻に なおして くらべます（`TamaSound.heardTime`。`getOutputTimestamp` を つかう）。
- はんてい：ぴったり ±0.08びょう・いいね ±0.18びょう（オニは ±0.06・±0.14）。たたかなかった 音符と、ウン（やすみ）の ところで たたいたのが ミス。ミス 3こ までなら クリア、0こなら 金のドロップ。1しょうせつ ミスなしで ドロップが とび、4しょうせつ ごとに 金。
- **ちょうせい**（さいしょの レベル）：カチッ（8はく）に 合わせて たたくと、たたいた ずれの まんなか（中央値）を この端末の ずれとして おぼえ（`tamadoro.rhythm.offset`、±0.3びょう まで）、ほかの レベルでは その ぶんを ひいて はんていします。ブルートゥースの イヤホンなど、音が おくれて 聞こえる 端末のため。5かい いじょう たたかないと、もういちど。

### じゆうにひこう（`js/piano.js`・`js/sing.js`）

- 音が鳴る けんばんで、すきなように ひいて あそびます（ドロップは なし）。けんばんは 画面の 左はしから 右はしまで ならび、数は 画面の はばで かわります（白いけんばん 1こ 40〜56px くらい。スマホの たてで 10こ、パソコンで 23こ など。まんなかの ドの あたりが まんなか）。むきや 大きさが かわると つくりなおします。指を すべらせると つぎつぎ鳴ります。
- 右上の「けんばんの はば」の スライダーで、白いけんばん 1この はばを 28〜100px で かえられます（けんばんの数は「画面の はば ÷ はば」）。えらんだ はばは この端末に おぼえておきます。
- 「音名かくにん」を ON にすると、さわった けんばんの 名前を、けんばんの上の ふきだしと 画面の まんなかに 大きく出します（黒いけんばんは「ド♯／レ♭」）。おとが ニャーの ときは、名前も ぜんぶ「ニャー」に なります。ON／OFF は この端末に おぼえておきます。
- 「おと」ボタンで、**ピアノ**（ふつうの 音）と **ニャー** を えらべます。えらんだ 音は この端末に おぼえておきます。
  - **ニャー**：ピアノの 音の かわりに、ネコの タマが「ニャー」と、ひいた けんばんの 高さで なきます（黒いけんばんでも なきます）。小さな口の形で、はなに ぬける こもった「ン」から ぱっと「ニャ」と はっきり なきます（息は まぜません）。のばすうちに すこし 口を すぼめ（ほんのり「ニャーォ」）、消える 直前に 2半音 下げます（とちゅうで はなしたときも、消えながら 下げます）。
  - 声は 録音ではなく、その場で つくります（`js/sing.js` のフォルマント合成）。のどの音を けんばんの 高さで つくり、「口の形」のフィルターに 通して 声に します。のばしている ところの 音程は ピアノと 同じです。けんばんごとの 大きさは、のばしている ところで そろえます。
  - 1回の声は 2.6秒（1.8秒から 小さくなる）。おしつづけても そこで おわり、はなすと（「ニャ」が 聞こえるくらい のこして）消えます。見えている けんばんの 声は、さきに つくっておきます。
  - `js/sing.js` には、ドを ひくと「どー」、レなら「れー」…と うたう 声（ドレミ）も 入っています（ためしに つくって とっておいたもの。いまは 画面から えらべません）。

## にがてちょうせん（たしざん・ひきざん・かけざん）

1問ごとに「苦手HP」（0〜30）を記録しています（`js/history.js`）。

| できごと | 苦手HP |
|---|---|
| まちがえた | +10 |
| 正解したけれど 4.5秒以上かかった（かくれにがて） | +3 |
| 3.5秒以内に正解した | −2 |

- レベル選択画面の「🔥 にがてちょうせん！」で切り替えます。レベルごとのボタンに、にがてな問題の数（`🔥3`、なければ `✨`）が出ます。にがてな問題がないレベル（まだ一度もあそんでいないレベルもふくむ）は、にがてちょうせん中は押せません。
- レベルを選ぶと、そのレベルの苦手HPが高い3問を、4周（計12問）出します。にがてが3問に足りないときは、ふつうの問題でうめます。
- 「👑 特訓コース」は、解放されたすべてのレベル（「5は2と」のような分けるレベルはのぞく）からにがてを集めます。ごほうびのドロップは、いちばんにがてな問題のあるレベルのドロップです。にがてな問題が1つもない（まだ あそんでいない など）ときは、押せません。
- 4回ともまちがえずに、平均3.5秒以内で答えられた問題は「✨卒業（HP 0）」になります。とてもにがてだった問題は「🔥パワーダウン（HP 8・あと1かい）」になります。
- にがてちょうせんの回は、ベストタイムやタイムのうつりかわりには入れません（記録には `weakChallenge: true` がつきます）。
- 出しかたは `js/engines/drill.js` の `WEAK_DECK_STYLE` で変えられます（`'intensive'`：いまの12問 ／ `'blend'`：苦手3問×3回＋まぜる問題6問の15問）。

## かけざんのレベル

1つの段に3つずつ（「n のだん」「n:さかさ」「n:バラバラ」）で Lv1〜27。そのあとに、Lv28 子オニ（青）（1〜5の段のバラバラ）、Lv29 子オニ（赤）（6〜9の段のバラバラ）、Lv30 オニ（黒）（すべての段）があります。オニの3つは、すべての段の「バラバラ」でドロップを1こ以上とると出てきます。ノーミスクリアで金のドロップ20こがもらえるのは Lv30 だけです。

## タマのきろく：ドロップびん

- びんは、コルクのふたの ガラスびん（太い胴・短く丸い肩・胴の73%の口）の形です。形は `js/records.js` の `buildJarShape` で決めていて、当たり判定（`collideWithJar`）と描画（`jarPath`）の両方がこれを使います。
- びんを開くと、ドロップがみんな同じ大きさでつまった状態からはじまり、新しいドロップ（さいごの8こまで）が上から落ちてきます。
- びんをタップするたびに、100こが1つの「100玉」に合体します。100玉が5こたまると、つぎのタップで「500玉」になり、500玉が2こたまると、つぎのタップで「1000玉」になります。
  合体するときは、粒がうずを巻いてグワッと吸いこまれ（光の輪・集中線・びんのふるえ）、ほんの一瞬 止まってから、パキーンとはじけます（びん全体の光・衝撃波・ガラスのかけら・まわりの玉を押しのける・「100!」「500!」「1000!」の文字）。
  演出は 100玉（白と水色）→ 500玉（ピンク・衝撃波2重）→ 1000玉（金色・衝撃波3重）と、大きな玉ほど派手で大きくなります。強さや色は `js/records.js` の `DropJar.FX`（100玉・500玉・1000玉それぞれ）で変えられます。
- ドロップが350こより多いときは、重くならないように 粒を間引いて描きます（`MAX_VISUAL_BALLS`。たとえば3589こなら、1つぶが約10こ分）。
  100玉・500玉・1000玉は合体すると正確な数になります。100こに満たない のこりの粒は、合体のたびに少しずつ（のこりの数 ÷ のこりの合体の回数）さりげなく「ほどけ」、さいごの合体で ちょうど ほんとうの数（3589こなら89こ）になります（`unpackSome`）。
- ぜんぶ合体したあとにタップすると、コルクのふたがポンと開いて、ドロップが飛び出します。
  コルクは、口に差しこむ部分が抜けるまでは まっすぐ上に抜け、抜けたら回りながら飛びます。落ちてきて傾いていると、角が口のふちに当たって跳ねかえり（3回まで）、まっすぐになると口にすべりこんで、コトンと小さく跳ねて おさまります（`stepLid`、`LID_...`）。
- ふた（口のふちより上）をタップすると、いつでも びんがコテンとたおれて、ドロップが画面いっぱいのテーブルにコロコロちらばります（`js/drop-table.js` の `DropTable`）。
  - テーブルは上から見たところ（重力なし）で、摩擦で止まります。色は びんのカードと同じ水色で、うしろの きろくの画面が 少しぼやけて すけて見えます（`css/records.css` の `.drop-table-bg`）。
  - びんは 左上のすみに たおれて、口が 右下のすみを むきます。うしろには 粒が1つぶ通れる すきま（`GAP`）を あけます。
  - びんの中に見えていた粒が、びんと いっしょに たおれて、口のほうへ ころがって 出てきます（`POUR_PULL`）。口から出た粒は テーブルの大きさに ふくらみ、おうぎ形に とびだします。遠くまで とぶ粒から先に出して、しばらくは ほかの粒の上を はねて こえる（`HOP_FRAMES`）ので、まんなかに かたまりません。
  - 出てくるのは、たおした ときの中身です。合体した玉（100玉・500玉・1000玉）はそのまま、のこりの粒は ほんとうの数で出ます。ただし テーブルの3わり（`AREA`）を おおう数まで（多いときは へらして出す）。見えていた粒より多いときは、のこりを 口から つづけて出します。粒は びんの中より少し大きく（`SIZE_UP`）します。
  - おそい端末では、出す粒を へらします。ふたを タップしたときに、この端末の速さを 一瞬 はかり（`bench`。テーブルと同じ ぶつかりの計算を ためしに うごかす）、「`BENCH_BUDGET` ÷ はかった時間」こまでに します。ぶちまけている あいだも 1こまの計算時間を 見はり、`SLOW_FRAME`（ms）を こえる こまが 3つ つづいたら、のこりを 口から 出しません（`watchSpeed`）。出なかった分は、おかたづけで 口から 入ってきて、いつもの びんに もどります。
    かげは、指で つまんでいる粒にだけ つけます（ぜんぶの粒に かげの まるを 塗ると、描く時間の 7わりくらいが かげに なって 重い）。
    目安（ぶちまけてから止まるまで、1こまの平均。画面の こまかさ 2倍）：ふつうの パソコンで 1000こ 約4ms。CPU が 4倍 おそいと 600こで 約13ms・1000こで 約18ms なので、そういう端末では 400〜600こくらいに へらします。
    軽くするための くふう（うごきは かえない）：ガラスの当たり判定は、とどかない ガラスの線や 胴の まんなかの粒を しらべない。粒どうしの ぶつかりは、マスわけを 数の ならび（Int32Array）で つかいまわす。速い粒が なく 指も ふれていないときは、1こまを わけずに すすめる（`SLOW_SPEED`）。
    おそい端末で 描くのが まにあわないときは、たった時間の ぶんだけ うごきを すすめてから 描くので、スローモーションに なりません（1回に `CATCH_UP` こままで）。
    （粒の絵を 画面に出す大きさで 写しておく くふうも ためしましたが、大きさが かわっていく粒が 多く、写しなおしが ふえて かえって 少し おそくなったので、やめました）
  - 止まったら 指でつまんで動かせて、はじくと すべります。何本の指でも動かせます。
  - びんの ガラスのかべ・口のふちには 当たり判定があります。口は あいていて、指で入れたり、はじいて ころがしこんだり できます（中では びんの粒の大きさに ちぢむ）。まわりの粒に そっと おされただけでは 入りません。かべを すりぬけて 出入りすることは ありません（`hitWall`）。
  - 「おかたづけ」の ボタンは 粒の うしろに あります（粒は canvas に描いて、ボタンより 手前。粒が ボタンに かくれない）。canvas は 指を とおすので、ボタンも おせます。ボタンの上の粒は、粒に ちょくせつ さわれば つまめて、そのときは ボタンを おしたことに なりません（`onDown`）。
  - 指で ぜんぶの粒を びんに入れたら、「おかたづけ」を おさなくても おかたづけに なります。つまんでいる粒が なく、ぜんぶの粒が `ALL_IN_FRAMES` こまの あいだ びんの中に いつづけたら はじめます（口から ころがり出たら かぞえなおし。テーブルの粒を 1つも 入れていないときは しない。`watchAllIn`）。
  - 「おかたづけ」を おすと、まず びんが おきあがって きろくの定位置に もどります（中に入れておいた粒も いっしょに）。
    つぎに、口に近い粒から じゅんばんに（びんの うしろを通って）山なりに とんできて、口の上の 真上から まんなかあたりへ とびこみ、そのままの いきおいで 落ちていきます（口の上で 止まらない。`flyAt`）。粒は つもった山の上に 落ちてから、斜面を ころがって 止まり、上の面は なだらかな山に なります。さいごに コルクが とんできて ふたをします。
    びんは、たおす前の中身に もどります（`saveJar`・`restoreJar`）。合体した玉（100玉・500玉・1000玉）は ほどけず、玉のまま もどり、合体の つづき（のこりの合体）も そのままです。合体の とちゅうで たおしたときは、その合体は とりけして、つぎに タップしたときに やりなおします。
    テーブルの粒は、もとになった びんの粒の場所へ もどります。びんの おくに あった分（見えていなかった粒）は、テーブルに 出なかった びんの粒の かわりになり、あまったら 口で すいこまれて 見えなくなります。たりない分は 口の上から 入ってきます（テーブルに出る数が びんに見えている数より 少ない、小さい画面の ときだけ）。
    つもる場所は、びんが おきあがる あいだに 少しずつ 計算して 先に 決めておきます（`packWork`。いちどに 計算すると スマホで 一瞬 かたまるので）。
    ① 1つぶずつ 口の下から 落として、下の粒の まわりを ころがし、2つの粒（か かべ）の あいだの くぼみに はまった所に おく（`pourer`。くぼみが 急な 坂に あるときや、高い所から 落ちて いきおいが あるときは、こえて ころがりつづける。坂の けわしさ `REPOSE`・落ちる はば `POUR_SPREAD`）
    → ② 重力で ならす（`SETTLE_STEPS`。とがった山や すきまが くずれる。大きい玉ほど 重い）→ ③ 重なりを なくす（`RELAX_MAX`）→ ④ 下の粒から じゅんばんに、まっすぐ 落ちられるだけ 落とす（`sinkDown`。かべや となりに よりかかって できた すきまを うめる）。
    まわりの粒に そって 止まるので、100玉・500玉・1000玉の まわりにも すきまが できません。粒どうしで おしあう計算は 見せている あいだには しないので、つもった粒は ぴたっと 止まり、ふたが しまったあとの びんは、つもった ならびと まったく同じです（あつまってくる時間 `FILL_FRAMES`）。
    ほかの画面へ行ったり 読みこみなおしたりすると、いつもどおり びんは つくりなおされます（合体は ほどける）。
  - ちらばった場所は保存しないので、ほかの画面へ行ったり 読みこみなおしたりしても、びんに もどっています。
- 落ちてきたドロップ（びんを開いたとき・ふたが開いて飛び出したとき）は、底や積もったドロップに強くぶつかると、玉1つぶんくらいまで跳ねます。
  跳ねるのは1つの玉につき2回まで。跳ねるたびに弱くなり、そのあとは今までどおりピタッと止まります。
  - 調整する数字は `js/records.js` の `DropJar` の上のほう（`BOUNCE_...`）にまとめてあります。
  - `BOUNCE_ENABLED: false` にすると、跳ね返りがなくなります（びんの形は いまのまま）。
  - 跳ね返りとびんの形を変える前の版（長方形のびん）は、ブランチ `anchor/dropjar-stable-6.3.6` に残してあります。`git checkout anchor/dropjar-stable-6.3.6 -- js/records.js index.html css/records.css` で、びんを元に戻せます。
  - `tests/dropjar.test.js` で、跳ねること・ずっと動きつづけないこと・びんの外や宙に浮いたまま止まらないこと を確かめています。

## よくある変更

- **レベルを追加・変更する**：`js/modes/addition.js` などの `levels` に1行足します。ボタンは自動でできます。
  ```js
  { label: 'Lv12もんだい', comment: 'こたえが20まで', drop: 'L',
    patterns: () => P.pairs(1, 9, 1, 9, (a, b) => a + b <= 20) },
  ```
- **ドロップの色を変える**：`img/drops/*.svg` の色（グラデーションの `stop-color` など）を直接書きかえます。
  （`tools/make_drops.py` は前のかんたんな球をつくるスクリプトなので、実行するといまのドロップが上書きされます）
  書きかえたら `node tools/make_drop_pngs.js` で、小さいドロップの PNG（`img/drops/small/`）もつくりなおします。
- **数字・記号・ひらがなの形を直す**：`tools/make_glyphs.py` の `BASE`（線の通り道）を変えて `python3 tools/make_glyphs.py`。
  字形は、教科書体の書き方のきまりに合わせて、タマドロのために一から描いたものです（フォントをなぞったものではありません）。
  あとで最終調整する点は、スクリプトの先頭に覚え書きがあります。
- **タマのセリフを変える**：`tashizan_message.json`。

| `notes_coins_3`・`notes_level_3_best_time` など | おんぷよみの ドロップ・ベストタイム（レベル1 が しくみ） |
| `tamadoro.notes.dataVersion` | おんぷよみの データの 版（js/modes/notes.js の `dataVersion` と ちがうと、まえの データを 消す） |
| `rhythm_coins_3` など | リズムの ドロップ（レベル1 が ちょうせい） |
| `tamadoro.rhythm.offset` | リズムの ちょうせいで はかった ずれ（秒。プラスは おそめに たたく） |
| `tamadoro.music.enabled` | `/music on` にしたか（`true` で「おんがくのへや」が出る） |
| `tamadoro.sound.muted` | 「おと なし」にしたか（`true` で ぜんぶの音を鳴らさない） |
| `tamadoro.piano.names` | じゆうにひこうの「音名かくにん」を ON にしたか |
| `tamadoro.piano.keyWidth` | じゆうにひこうの「けんばんの はば」（px。ないときは 画面の はばに合わせた めやす） |

「データをセーブ」は localStorage をまるごと `tamadoro_月日時分.txt` に書き出します。

「データをロード」は、読みこみかたを2つから選べます。

- **いまのデータに たして よみこむ**：ファイルにあるデータだけ入れかえます。ファイルにないデータ（ほかのモードのドロップ・記録・設定）は、そのままのこります。
- **ぜんぶ うわがきして よみこむ**：いまの localStorage をぜんぶ消してから、ファイルのデータを入れます。ファイルがこわれているときは、何も消しません。

どちらも、読みこんだあとに `tamadoro.schema` がなければ（むかしのアプリのセーブファイルなど）、ドロップを記録に取りこみます。

## テスト

`tests/` に、ブラウザを自動で動かして確かめるテストがあります（Node.js と Playwright が必要）。

```sh
cd tests
npm install
npx playwright install chromium
npm test
```
