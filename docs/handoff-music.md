## マスタークラス（きょくふう）

### 曲調（`js/songs.js`）
- 15 系統・33 曲調（`FAMILIES`・`STYLES`）。1曲は 8つの 和音、となりあう 和音は ちがう、さいごは ド（マイナーは ラ）
- ノブ：曲調・系統・リズムに `weight`（0 で 出ない、2 で 2ばい）
- **にほん**：ヨナぬき（ドレミソラ）・みんよう（ラドレミソ。伴奏は 空5度 A5 など）。曲調の `scale` の 音だけで メロディ（`scaleWhites`。となりも 音階の となり）
- **おきなわ は ほりゅう**（ユーザー：「沖縄感が 難しい」）。系統の ノブ 0。消してはいない（`/song okinawa` で ためせる。一覧では「おやすみ中」）
- `/song`⏎ で 一覧から えらぶ（マスタークラスの 画面なら その 曲で やりなおし）。`/song jazz`⏎・`/rhythm genki`⏎ でも きめられる（`off`⏎ で もどす）

### リズム（4/4拍子）
- 1つの 和音 ＝ 1小節。● ＝ 4ぶおんぷ、○ ＝ 4ぶきゅうふ。**4小節めと 8小節めは かならず ●●●○**（いきつぎ）
- `RHYTHMS`：げんき（ユーザーの 案A）・はずむ・せつない（ユーザーの 案B）・うたう・ずらす（1拍めが ○。ジャズなど。ユーザー：「先頭に 休符が あっても 音符を ひくだけ」）。`tempo`（げんき 112・はずむ 108・せつない 96・うたう 96・ずらす 104）
- 休符は おさなくて いい。まえの 音を ひくと すこし 光って すぐ つぎへ（その子の テンポでは またない）

### うたう メロディ（`TamaSongs.make`）
- 試作で「和音の 音だけ」と「経過音いり」を 聞きくらべて **経過音いりに きまった**（ユーザー：「歌いやすく、吹奏楽でも こちらが 主流」）
- つよい 拍は 和音の 音、よわい 拍は 経過音・刺繍音も。となりへの うごきが 中心、とんだら もどる
- 起（1〜2）・承（3〜4。3小節めは 1小節めの かたち）・**サビ（5〜7、ときどき 5〜6）**・結。サビは 跳躍 OK
- 系統ごとの 性格（`FAMILIES[].melody`：高さ・広さ・とび・サビの むき）。サビの むき：もりあがる・しずむ・とびあがる・**ぐぐぐっと**（もりあげやすい 曲調に ときどき。ユーザー：「そればかりだと 飽きる」）

### 音色（`FAMILIES[].sound`・`TamaSound.VOICES`）
- けんばん（メロディ）と 伴奏の 音色を 系統ごとに。README の「曲調ごとの 音色」の 表
- **伴奏に はじく 音を つかわない**（ユーザー：「和音が ひびかず、はじく 音だけで あわない」）。にほんの 伴奏は しゃくはち、ボサノバの 伴奏は ストリングス
- こと（はじく 音）は Karplus-Strong。くりかえしが n − 0.5 サンプルに なる ぶん、再生の はやさで 高さを なおしている（なおさないと 20セントほど ずれる）

### えんそうの ながれ
1. れんしゅう 8もん（1小節ずつ、コード名つき。サビの 小節は「（サビ）」）→ まちがえた フレーズを もういちど
2. とおし えんそう：**イントロ 2小節**（曲の さいごの 2つの 和音 → はじめの 和音と カウント 1・2・3・4。その あいだは うけつけない）→「さあ どうぞ！」→ **まって くれる 伴奏**（`keysAccomp`：小節の はじめの 音で その 和音が 鳴りつづける。のびる 音色は のばす、きえる 音色は ゆっくり 分散和音。20びょう ひかないと きえる）。じぶんの ペースで、まちがえても とまらない
3. ひきおわり：「えんそう おわり！」と 2だんめに **とくちょうを ほめる ことば**（点数は 出さない）。ボタンは「この きょくを もういちど」（イントロから ひきなおす）・「じぶんの えんそうを きく」・「ドロップを もらう」
4. **すぐに じぶんの えんそうが ながれる**（イントロなし。曲の 1小節めから → アウトロ：下属和音 → 主和音）

### えんそうの ひょうげん（`TamaSongs.expressive`）
- ユーザー：「つっかえ・ずれも 反映したい。ミスを 強調せず、お洒落な 演奏 と 肯定的に」
- ずれ → **ゆれ**（ふだんの はやさ から の ずれを 35%・4分の1拍 まで・ならす）、つっかえ → **ため**（1拍・1曲 3かい まで・伴奏は 分散和音で まつ）、まちがえた 音 → **かざりの 音**（正しい 音の すこし まえ・2つ まで・5度 いないに よせる。オクターブ ちがいの 同じ 音は かざりに しない）
- とくちょうの ことば（`traitWords`）：ゆったり バラードふう／ちょうどいい はやさ／いきいき アレグロふう、リズム ぴったり／ロマンチックな ゆれ、ため の かず、かざりの 音 の かず

## つぎの アイディア（まだ 入れていない もの）

ユーザーと 話した ものを、だれの 案か・どこまで 話したか と いっしょに。

### きょくふう の 伴奏・聞こえかた
- **「きく」の 曲調ごとの 伴奏の 型**（Claude の 案B。ユーザー「いいですね」、まだ 作っていない）：ポップス・ロックは 4分で きざむ、どうようは ズン・チャッ、ボサノバ・ブルースは はねる、ゲームは 分散和音、きょうかいは のばす。いまは どの 曲調も 1拍めと 3拍めに 和音と ベース
- **再生の はやさを その子の はやさに あわせる**（Claude の 案。へんじ まち）：ゆっくり ひいた 子は「ゆったり バラード」として 再生
- **サビで 自動で もりあげる**（Claude の 案。へんじ まち）：再生の とき サビで 伴奏・音量を すこしずつ 大きく
- **おわりに 拍手と「ブラボー！」**（Claude の 案。へんじ まち）：どの 演奏でも。とくちょうで 拍手の しゅるいを かえる だけ
- **じぶんの メロディを ほかの 曲調で アレンジして きく**（Claude の 案。へんじ まち）：ひいた メロディを ジャズ風・ボサノバ風の 伴奏と 音色で
- 試聴して もらう こと（ユーザーの へんじ まち）：ゆれの 強さ（35%）、かざりの 音が まちがいに 聞こえないか、イントロ 2小節の ながさ、分散和音の 大きさ・はやさ、ストリングスを 6びょうごとに 鳴らしなおす つなぎめ

### 見せかた・あそび
- **ステージの 見せかた**（Claude の 案。ユーザー「魅力を感じる」）：とおし えんそうの あいだ まわりを 暗く・がくふに スポットライト・タマが 観客で ゆれて おわったら 拍手
- **曲調ごとの 背景**（Claude の 案）：シティポップは 夜の 紺、ゲームは ドット絵、きょうかいは ステンドグラス など
- **曲名と きょくノート**（Claude の 案。ユーザー「魅力を感じる」）：できた 曲に 名前（「タマの よるの さんぽ」など）を つけて、とくちょうの ことばと いっしょに 保存。あとで 聞ける。系統を あつめる 図鑑に すると ドロップとも むすびつく

### 曲調・メロディ
- **都節（ミファラシド。ミで おわる）**：おわりの 音が ド・ラ 以外に なるので、曲調の `key` の しくみを ひろげる ひつようが ある
- **おきなわ風**（ほりゅう中）：「沖縄感」を 出すには、三線の 音色・リズム（はねる・カチャーシーの きざみ）・和音の えらびかた を いっしょに 見なおす ひつようが ありそう
- メロディの くりかえし（モチーフ）を もっと はっきり（いまは 3小節めが 1小節めを まねる だけ）

### 画面の こと（まえから ある もの）
- スマホ幅の レベル選びの 画面で、ボタンの 文字が たてに おりかえして かさなる（まえの 版から。ユーザーに つたえ ずみ。直すなら べつの 作業）
