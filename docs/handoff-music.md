## すすめかたの きまり（ユーザーと やってきた ながれ）

- 変更したら、どんなに 小さくても バージョンを 1つ 上げる（`index.html` の `#version`、`tests/basic.test.js` の「バージョン表記」、`tests/fixes-v6.test.js` の「フッターの表記」）。CLAUDE.md の とおり
- `cd tests && npm test` を 通してから コミット。**ぜんぶで 10分 以上 かかる**ので、うしろで 流して おわりを まつ。`tests/music.test.js` だけなら 4〜5分（`BASE_URL` を わたして 直接 うごかせる）
- コミットしたら ブランチへ push。ユーザーは そのつど「VSCode側に引っ張るコード」を ほしがる（`git fetch origin` → `git switch <作業ブランチ>` → `git pull origin <作業ブランチ>` を 1つずつ コードブロックで）
- 「メインに上げて」と 言われたら PR を 作って マージ。マージしたら、つぎの 作業は 最新の main から
- 画面を かえたら スクリーンショット、音を かえたら 試聴用の wav を 作って 見せる（こちらは 耳で きけないので、そう つたえる。下の「試聴用の 音の つくりかた」）
- 大きな 変更は、まず 案を 出して ユーザーと きめてから。音は 試作 → 聞きくらべ → きめる、の じゅんが よかった
- コードの コメント・README は、ひらがな多めの やさしい 日本語（いまの 書きかたに あわせる）
- 説明と 動きが ちがうときは、動きを 正しいと して 説明を なおす

## マスタークラス（きょくふう）

### 曲調（`js/songs.js`）
- 15 系統・33 曲調（`FAMILIES`・`STYLES`）。1曲は 8つの 和音、となりあう 和音は ちがう、さいごは ド（マイナーは ラ）
- ノブ：曲調・系統・リズムに `weight`（0 で 出ない、2 で 2ばい）
- **にほん**：ヨナぬき（ドレミソラ）・みんよう（ラドレミソ。伴奏は 空5度 A5 など）。曲調の `scale` の 音だけで メロディ（`scaleWhites`。となりも 音階の となり）
- **おきなわ は ほりゅう**（ユーザー：「沖縄感が 難しい」）。系統の ノブ 0。消してはいない（`/song okinawa` で ためせる。一覧では「おやすみ中」）
- `/song`⏎ で 一覧から えらぶ（マスタークラスの 画面なら その 曲で やりなおし）。`/song jazz`⏎・`/rhythm genki`⏎ でも きめられる（`off`⏎ で もどす）

### リズム（4/4拍子）
- 1つの 和音 ＝ 1小節。● ＝ 4ぶおんぷ、○ ＝ 4ぶきゅうふ。**4小節めと 8小節めは かならず ●●●○**（いきつぎ）
- `RHYTHMS`：げんき（ユーザーの 案A）・はずむ・せつない（ユーザーの 案B）・うたう・ずらす（1拍めが ○。ジャズなど。ユーザー：「先頭に 休符が あっても 音符を ひくだけ」）。`tempo`（げんき 112・はずむ 108・せつない 96・うたう 96・ずらす 104）
- 休符は おさなくて いい。まえの 音を ひくと すこし 光って すぐ つぎへ（その子の テンポでは またない）

### うたう メロディ（`TamaSongs.make`）
- 試作で「和音の 音だけ」と「経過音いり」を 聞きくらべて **経過音いりに きまった**（ユーザー：「歌いやすく、吹奏楽でも こちらが 主流」）
- つよい 拍は 和音の 音、よわい 拍は 経過音・刺繍音も。となりへの うごきが 中心、とんだら もどる
- 起（1〜2）・承（3〜4。3小節めは 1小節めの かたち）・**サビ（5〜7、ときどき 5〜6）**・結。サビは 跳躍 OK
- 系統ごとの 性格（`FAMILIES[].melody`：高さ・広さ・とび・サビの むき）。サビの むき：もりあがる・しずむ・とびあがる・**ぐぐぐっと**（もりあげやすい 曲調に ときどき。ユーザー：「そればかりだと 飽きる」）

### 音色（`FAMILIES[].sound`・`TamaSound.VOICES`）
- けんばん（メロディ）と 伴奏の 音色を 系統ごとに。README の「曲調ごとの 音色」の 表
- **伴奏に はじく 音を つかわない**（ユーザー：「和音が ひびかず、はじく 音だけで あわない」）。にほんの 伴奏は しゃくはち、ボサノバの 伴奏は ストリングス
- こと（はじく 音）は Karplus-Strong。くりかえしが n − 0.5 サンプルに なる ぶん、再生の はやさで 高さを なおしている（なおさないと 20セントほど ずれる）

### ステージ（Ver.6.3.77。`keysStage`・`keysAudienceClap`・css/music.css の「ステージ」）
- とおし えんそうの イントロから、その 曲を はなれる（べつの 曲・えんそうを おわる・ほかの 画面）まで `#keysScreen.on-stage`
- 暗く するのは がくふの カード（`.score-card`）の 影を 200vmax に ひろげる しかけ。けんばん（z-index 2）・ボタン・ことばは その うえで 明るい まま。ことばの 色は 明るく かえる。上から 光の すじ（`.keys-spot`）
- 観客の タマ（index.html の `.keys-audience`。ホームの タマの 絵を うつした SVG。手だけ べつ）：けんばんの 左うえ。曲の 拍（`--beat`）で ゆれる。ひきおわると 1.8びょう 拍手、「べつの 曲」「えんそうを おわる」の 拍手の あいだも 拍手
- ひきおわった ときは 見た目の 拍手だけ（音の 拍手は「べつの 曲」「えんそうを おわる」の とき。じぶんの えんそうが すぐ ながれる ため）
- 観客の タマは つもった ドロップ（`.coin.keys-pile`、z-index 3）より 手前（4。Ver.6.3.78。ユーザー：「タマの 場所は かえたくない。ドロップの 上に かさなって 最前面に」）。とんでくる ごほうびの ドロップ（6）より うしろ。クリックは とおす

### きょくノート（Ver.6.3.79。`js/song-note.js`）
- ひらきかた：おんぷよみの レベルを えらぶ 画面の「📖 きょくノート」（`#goToSongNote`。おんぷよみの ときだけ）
- **ボタンで えらんだ 曲だけ** のこす（ユーザーの えらび）：ひきおわった 画面の「ノートに のこす」→「のこしたよ！」（もう おせない）。「この 曲を もういちど」で ひきなおすと また のこせる
- のこす もの：曲調 id・リズム・8小節（notes・chord・rhythm・sabi）・ひいた きろく（t・wrongs）・はやさ（pace）・とくちょうの ことば・名前の seed。50曲まで（`tamadoro.notes.songbook`）
- きく：`keysPlaySong(song, take, { onEnd })`（「じぶんの えんそう」と 同じ。`keysPlayback` は これを よぶ だけ に した）
- **曲名**：自動（`SCENES`[系統] × `PIECES`[はやさ]、「タマの 」つきと なし）。こうほを 曲の id で まぜて、seed ばんめ。「ほかの なまえ」で seed + 1。**ノブ `RENAME`**（true：かえられる。false：自動の まま。ユーザー：「後でノブで 内部的に 変更できるように」）
- **きょくふう ずかん**：`keysPerformFinish`（べつの 曲・えんそうを おわる）で `addFamily`。はじめてなら ごほうびの ドロップは 金（`createRewardCoin` の 3つめ `forceGold`）。ことば「はじめての ○○風！ ずかんに のったよ。きんの ドロップ！」。まえの プレイは 系統の きろくが ないので、さいしょは 0
- けす：2かい おす（「ほんとうに けす？」）
- セーブ（歯車）：Ver.6.3.80 から `tamadoro_月日時分.json`（`{ format: 'tamadoro-save', version: 2, data: 入れ子の JSON, text: JSON で ない 文字 }`。ユーザー：「今後は JSON、読みこみは txt も」）。ロードは まえの `.txt`（`{ キー: 文字 }`）も 読める（`js/data-modal.js` の `buildSaveFile`・`readSaveFile`）
- 「いまのデータに たして よみこむ」：きょくノートと ずかんは 入れかえずに あわせる（`TamaStore.MERGERS` に `mergeSongs`・`mergeFamilies`。同じ 曲は 1つで ファイルの ほう、新しい じゅん、50曲まで）。ほかの データは これまでどおり ファイルの ほうに 入れかわる

### 伴奏の 型（`TamaSongs.ACCOMPS`・系統の `accomp`）
- ひきおわると ながれる「じぶんの えんそう」の 伴奏（`keysPlayback`）。とおし えんそう中の まって くれる 伴奏（`keysAccomp`）は べつ（Ver.6.3.85 で のばす 伴奏 ＋ ついてくる ベースに した）
- Claude の 案B（ユーザー「いいですね」→「実装をお願い」）：ポップス・ロックは **4分で きざむ**、どうようは **ズン・チャッ**、ボサノバは **はねる**（ベース ドーン・ド ドーン・ド ＋ うすく のばす ストリングス）、ブルースは **はねる**（シャッフル。あるく ベース ＋ はねた うら拍の 和音）、ゲームは **分散和音**（8分音符）、きょうかいは **のばす**。ほかは **ふつう**（1拍め・3拍め）
- 1小節ぶんの 鳴らしかたを `bar(c)` で データに（`at` 拍め、`chord: true` か `notes`、`gain`、`hold` 拍、`strum`）。ためは `expr.warp` で うしろへ ずらし、のばす 拍も ためで のびる
- テストで かざりの 音を `gain === 0.22` で かぞえているので、伴奏の 音に 0.22 を つかわない

### えんそうの ながれ
1. れんしゅう 8もん（1小節ずつ、コード名つき。サビの 小節は「（サビ）」）→ まちがえた フレーズを もういちど
2. とおし えんそう：**イントロ 2小節**（主和音 → はじめの 和音へ ひっぱる 和音（`keysLeadChord`）を のばして カウント 1・2・3・4。その あいだは うけつけない。はいりの 半拍 まえから うけつける）→「さあ どうぞ！」→ 1音めと いっしょに はじめの 和音 → **まって くれる 伴奏**（`keysAccomp`：小節の はじめの 音で その 和音が 鳴りつづける。いつも のばす 音色（`keysPadVoice`。メロディと ちがう 音色）で きざまない。ベース（ひくい ピアノ）が 和音の かわりめに ねもと、そのあと 1音ごとに 5度・ねもと と ついてくる。20びょう ひかないと きえる）。じぶんの ペースで、まちがえても とまらない
