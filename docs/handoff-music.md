- コードの コメント・README は、ひらがな多めの やさしい 日本語（いまの 書きかたに あわせる）
- 説明と 動きが ちがうときは、動きを 正しいと して 説明を なおす

## おんぷよみの レベル（ユーザーと きめた こと）

| レベル | 中身 | きめた こと |
|---|---|---|
| しくみ | せんを「1ぽんめ・2ほんめ・3ぼんめ…」と かぞえる → ドは 下の みじかい せん → のぼる・くだる（せん／あいだ の ふだ）→ つづけて 読む | はじめは 1ぽんめが やさしく 点滅「おしてね」。ドの けんばんに わっか。正解は キラリン → すこし あとに つぎの 音符（おした音が つぎの 音符だと まちがえないように）。歌声つき。まちがえても しっぱいに しない |
| Lv1 せんの おだんご | ド・ミ・ソ | お手本（名前・わっか）→ 1おんと おだんごを まぜる |
| Lv2 あいだの おだんご | レ・ファ・ラ | **レは ドの せんと 1ぽんめの「あいだ」の なかま**。正解の 和音は **Dm だけ** |
| Lv3 おだんご まぜ | 6つの 音 | お手本なし |
| Lv4 おだんごの つづき | ドミソシ・レファラド（4つだま） | おだんごが そろうと Cmaj7・Dm7。**1おんは これまでと 同じ ひびき**（ドミソ・たかいド は C、レファラ は Dm、シは Em） |
| Lv5 ド〜ド | 名前なし | 「けんばんの よみかた」スイッチ（ON で 名前。はじめは いつも OFF） |
| Lv6 うえの おと | うえの おだんご（シ・たかいレ・たかいファ＝G7／たかいド・たかいミ・たかいソ＝C） | けんばんは あかるい ところを 右に（左に くらい けんばん） |
| Lv7 メロディ | とびはねる メロディ | C の つぎの C は Am か C7、ときどき Fm（借用和音）。**けんばんの Lv7 は もとの まま**（かんたんな 基礎） |
| Lv8 きょくふう | 曲調の 8フレーズ → とおし えんそう | 下の「Lv8」 |
| オニ | ぜんぶ まぜて | Lv8 の メロディも まぜる（まだ） |

- おだんごの 色は **音の 色**（けんばんの 名前の 色を あわく）。ドミソ と レファラ は ちがう 色、シは むらさき、たかいドは ドと 同じ。「色で こたえが わかって しまう」点も つたえたうえで、この形で OK と なった
- 算数の「おたすけだんご」も、Lv5 と 同じ ON／OFF スイッチの 見た目（中身は チェックボックスの まま）

## Lv8 きょくふう（いまの しくみ）

- 曲調は 13 系統・29 曲調（`TamaSongs.STYLES`）。1曲は 8つの 和音、となりあう 和音は かならず ちがう、さいごは ド（マイナーは ラ）で おわる
- メロディは その 和音の 音のうち 白いけんばん（ド〜たかいソ）だけ。どの フレーズにも 3度より 大きい とび
- **ノブ**：曲調の `weight` と 系統（`FAMILIES`）の `weight`。0 で 出ない、2 で 2ばい
- `/song jazz`⏎ などで 曲調・系統を きめて ためせる（`/song off`⏎ で もどす。Enter で きまる）
- すすみかた：れんしゅう 8もん（コード名つき）→ まちがえた フレーズを もういちど → とおし えんそう（ぜんぶの がくふ、フレーズの はじめで 和音が ついてくる、じぶんの ペース、まちがえても とまらない）→ ジャーン → 「じぶんの えんそうを きく」（ひいた タイミングで 伴奏つき）／「ドロップを もらう」
- 「通し演奏は 自動で 流れるのではなく、ユーザーが 演奏して 達成感を 得る」が ユーザーの ねらい

## データ
